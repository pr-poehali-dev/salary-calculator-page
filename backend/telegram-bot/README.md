# Хелпер — Telegram бот для курьеров

## Настройка ежедневной сводки

Бот отправляет утреннюю сводку каждый день в 9:00 с информацией о том, кто сегодня работает.

### Шаги настройки:

**1. Получите ID вашей группы в Telegram:**
   - Добавьте бота @userinfobot в вашу группу
   - Он пришлет ID группы (например: `-1001234567890`)
   - Скопируйте это число целиком (вместе с минусом!)

**2. Добавьте секрет TELEGRAM_GROUP_CHAT_ID:**
   - Вставьте скопированный ID в поле секрета
   - Например: `-1001234567890`

**3. Настройте cron для ежедневного запуска:**

Используйте любой бесплатный cron-сервис, например:
- [cron-job.org](https://cron-job.org)
- [EasyCron](https://www.easycron.com)

**Настройки cron:**
- **URL**: `https://functions.poehali.dev/b9cc37e2-8ce1-432e-ac85-b2c09fd13863?action=daily`
- **Метод**: GET
- **Время**: каждый день в 9:00 (по вашему часовому поясу)
- **Расписание в формате cron**: `0 9 * * *`

### Проверка работы:

Можете проверить прямо сейчас, открыв в браузере:
```
https://functions.poehali.dev/b9cc37e2-8ce1-432e-ac85-b2c09fd13863?action=daily
```

Если всё настроено правильно — в группу придет сводка дня! 🎉
